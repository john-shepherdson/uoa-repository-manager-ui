Metrics Configuration & Software Details

OpenAIRE's usage statistics service tracking code is maintained on Github as a patch for various versions of DSpace (https://github.com/dimitrispie/OpenAIRE-Piwik-DSpace) and as an Eprints plugin for version 3 (https://github.com/dimitrispie/EPrints-OAPiwik).

Please, change the configuration files with the following values, generated for your site:

PiwikID
104
AuthenticationToken
106629304

Details for the configuration files are given in the README of the tracking code.

NOTE - You will be informed by e-mail that the installation of the tracking code has been validated and when the usage statistics will be available.
